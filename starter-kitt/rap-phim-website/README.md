# CineBox – Đặt vé xem phim mini

Website **đặt vé** *xem phim mini* tiện lợi và nhanh chóng.
## Bảng thư mục 
| Thư mục | Nội dung | Chú Thích |
| :--- | :--- | :--- |
| `logs/` | Lọc các dòng lỗi của dự án  | Thống kê các lỗi|
| `Web/` | Tài nguyên tĩnh | Chứa hình ảnh, icon và CSS |
| `data/` | Bảng giá cả  | Thống kê giá cả vé xem phim trong tháng 11  |

## Lệnh liệt kê dự án 
```powershell
Get-ChildItem -Recurse -Force
```
